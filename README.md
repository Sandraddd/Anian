# 阿念

阿念是一只运行在 macOS 桌面上的像素小狗。它可以陪你管理待办、同步日历与提醒事项，也能用倒计时或正计时陪你专注。

## 主要功能

- 桌面像素小狗与点击、拖拽互动
- 待办添加、完成、用时记录
- 今日日历和提醒事项同步
- 番茄钟倒计时与正计时
- 底部进度跑道：阿念的屏幕位置代表专注进度
- 正计时模式每 25 分钟循环跑一圈，直到用户手动结束

## 下载与运行

1. 下载 `release/Anian-1.0.0-macOS-arm64.zip`。
2. 解压后打开 `阿念.app`。
3. 首次使用日历或提醒事项时，按 macOS 提示授权。

系统要求：macOS 15 或更高版本，Apple Silicon。

> 当前发布包使用本地签名。如 macOS 阻止首次打开，请在“系统设置 → 隐私与安全性”中选择仍要打开。

## 从源码构建

需要 macOS 15+ 和 Xcode Command Line Tools。

```bash
chmod +x build.sh
./build.sh
```

构建结果位于 `build/阿念.app`。

## 项目结构

- `阿念.swift`：应用主程序
- `Resources/`：像素动画、图标和语料库
- `validate_atlas.swift`：精灵图帧完整性检查
- `阿念动作映射.md`：素材帧与动作映射
- `build.sh`：本地构建脚本
- `release/`：可直接下载的发布包及 SHA-256 校验值
